## RFC 8342 — Network Management Datastore Architecture (NMDA)

- **Home**: https://www.rfc-editor.org/rfc/rfc8342
- **Key concepts**: named datastores — `running`, `candidate`, `startup`, `intended`, `operational`; `<operational>` holds applied configuration plus protocol-derived state
- **Relevance**: standard vocabulary for separating intended from operational device configuration; prior art for the device-config subset of the modality dimension
