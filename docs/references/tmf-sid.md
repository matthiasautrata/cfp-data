## TM Forum SID and Open APIs

- **Home**: https://www.tmforum.org/oda/information-systems-architecture/ ; API specs TMF639 (resource inventory), TMF638 (service inventory)
- **Key concepts**: telecom-wide information model — resource, service, customer, product domains; REST APIs over the model
- **Relevance**: complete and heavy. Rational only alongside an existing OSS/BSS integration; not adopted at this stage
