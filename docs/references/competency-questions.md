## Competency Questions

- **Home**: Grüninger and Fox, "Methodology for the Design and Evaluation of Ontologies", IJCAI-95 workshop
- **Key concepts**: requirements stated as questions a model must be able to answer; used to scope and to evaluate the model
- **Relevance**: form for use cases; each question doubles as an acceptance test and an agent evaluation item. The form is adopted, not any ontology stack
- **Used by**: [Stakeholders & Use Cases](../problem/02-stakeholders-use-cases.md)
