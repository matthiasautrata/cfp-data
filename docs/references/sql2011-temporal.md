## SQL:2011 Temporal Tables

- **Home**: ISO/IEC 9075-2:2011 (SQL/Foundation)
- **Key concepts**: application-time period tables (valid time); system-versioned tables (record time); both together = bitemporal
- **Relevance**: Standard semantics for bitemporal facts; candidate basis for storage and query
