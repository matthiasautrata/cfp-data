## LinkML

- **Home**: https://linkml.io/
- **Key concepts**: YAML schema — classes, slots, enums, types, inheritance, mixins, mappings to external vocabularies; generators emit JSON Schema, SQL DDL, JSON-LD, OWL, SHACL, GraphQL, docs; slot units via UCUM codes
- **Relevance**: one canonical definition compiled to many artifacts; keeps an RDF option open without committing to it. A tooling choice, not a standard
- **Used by**: [Idea: model standards landscape](../ideas/model-standards-landscape.md)
